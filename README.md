This project is intended for learning Claude Code using VSC.

Requirements: Python 3.14.

To set up the project after cloning it (once, in the VSC terminal):

```powershell
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

To run the application:

```powershell
streamlit run Testing.py
```

To test application deployed in Streamlit:
https://diceroler.streamlit.app/

If you want to use also Streamlit to deploy for testing and evaluation purposes, synchronize your own GitHub with your VSC environment with the Testando application and deploy it using:

https://share.streamlit.io/

See: https://docs.streamlit.io/deploy/streamlit-community-cloud/share-your-app
